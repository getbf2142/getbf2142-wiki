Reclamation's servers run their own versions of the maps, so you'll need their map pack, or at least the maps currently in rotation, to join. Curious what's inside? See the [map list](https://www.battlefield2142.co/maps/v3.html).

<GuideSummary step={5} time="15 minutes" optional>

Only needed for the Reclamation servers. Download the pack and install it with the Hub's <mark class="ui">MapPack Installer \*</mark>, or grab just the maps you need.

</GuideSummary>

<details id="is-this-pack-optional-or-mandatory">

<summary>Do I need this?</summary>

Only if you want to play on Reclamation servers. For singleplayer, LAN or Remaster, you can skip it.

</details>

<details id="i-already-have-an-older-map-pack">

<summary>I already have an older map pack. Do I need the new one?</summary>

Yes. The pack was updated on 19 June 2026, and the servers expect the latest maps. Download the new pack and install it the same way.

</details>

<details id="where-can-i-find-the-installed-maps">

<summary>Where do the maps go?</summary>

Into `\mods\bf2142\Levels` inside your game folder, with one folder per map placed directly in `Levels`.

</details>

## Installing the complete pack

<Aside type="note">

If the Hub shows an `mdIBF.DNS` error when downloading, just download the pack from [Downloads](#downloads) and continue from step 3.

</Aside>

<Steps>

1. Start BF2142 Hub.

1. In the <mark class="ui">Download</mark> tab, double-click <mark class="ui">BF2142 Reclamation MapPack</mark>. Your browser opens the download page.

1. Download `Reclamation_mappack_2025.1.zip` (5.88 GB) there, or from [Downloads](#downloads).

1. Back in the Hub, click <mark class="ui">MapPack Installer \*</mark> and select the `.zip` you downloaded. A command window opens and closes by itself when it's done.

</Steps>

Prefer doing it by hand? Extract every map folder from the `.zip` straight into `\mods\bf2142\Levels`, with no extra parent folder in between.

## Installing individual maps

Only need the maps currently in rotation? Grab them one by one:

<Steps>

1. Start BF2142 Hub.

1. In the <mark class="ui">Download</mark> tab, click <mark class="ui">Individual Maps</mark>.

1. Select maps under <mark class="ui">Available Maps</mark> and click <mark class="ui">>></mark> to download them. To remove one, select it under <mark class="ui">Installed Maps</mark> and click <mark class="ui">\<\<</mark>.

</Steps>
