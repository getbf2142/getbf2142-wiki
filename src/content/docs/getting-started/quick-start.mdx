The short version, for people who just want to play. Each step links to its full guide, so if something goes wrong, open that one.

<Aside type="note">

New to old PC games, or something already installed? [Before proceeding](/getting-started/before-proceeding/) helps you pick exactly the guides you need.

</Aside>

<Steps>

1. **Install the game** <GuideLink href="/getting-started/download-and-install-bf2142/" />

   Download the [Standard Edition v1.01](https://mediafire.com/file/g6xhktutdtnpgs3/BF2142_Setup.rar/file) (3.24 GB), extract it and run `setup.exe`. Use this serial key:

   ```text
   E6HH-DWUG-U8X1-R8F0-1911
   ```

   Skip BattleCammo, GameSpy Comrade, the EA registration and PunkBuster. Don't launch the game yet.

1. **Update to v1.51** <GuideLink href="/getting-started/download-and-install-v1_51-patch/" />

   Run the [v1.51 Full Installer](https://www.moddb.com/downloads/start/193467/all) (2.3 GB). Windows may warn you. Click <mark class="ui">More info</mark> → <mark class="ui">Run anyway</mark>.

1. **Install BF2142 Hub** <GuideLink href="/getting-started/download-and-install-bf2142-hub/" />

   Download and install [BF2142 Hub 2](https://www.moddb.com/downloads/start/210984/all) (1.2 MB).

1. **Get online with OpenSpy** <GuideLink href="/getting-started/apply-openspy-patches/" />

   Run the Hub as administrator. On the <mark class="ui">Help</mark> tab, check <mark class="ui">GamePath</mark>, pick <mark class="ui">OpenSpy</mark> under <mark class="ui">Redirects\*</mark> and click <mark class="ui">Install</mark>. All four ticks should turn <mark class="ui ui-green">green</mark>.

1. **Get the map pack** _(optional)_ <GuideLink href="/getting-started/install-map-pack/" />

   Only needed for the Reclamation servers. Download the [Reclamation Map Pack](https://www.moddb.com/downloads/start/287584/all) (5.88 GB) and install it with the Hub's <mark class="ui">MapPack Installer \*</mark>.

1. **Create your account** <GuideLink href="/getting-started/create-account/" />

   Launch the game from the Hub, click <mark class="ui">CREATE NEW ACCOUNT</mark> and create a soldier. Then set your resolution under <mark class="ui">OPTIONS</mark> → <mark class="ui">VIDEO</mark> and turn <mark class="ui">ANTI-ALIASING</mark> off.

1. _**Done. See you on the battlefield!**_

</Steps>
