Guides ① - ⑥ take you from nothing to playing online, in order. Depending on your setup, you can skip some of them. Answer the two questions below and you'll know exactly which ones you need.

<Aside type="tip">

Just want the short version? Try the [Quick start](/getting-started/quick-start/).

</Aside>

## 1. Is the game installed?

<details id="no-i-dont-have-the-game-installed">

<summary>No, I don't have the game installed</summary>

Start from the top: [① Install BF2142](/getting-started/download-and-install-bf2142/) → [② Install v1.51 patch](/getting-started/download-and-install-v1_51-patch/)

</details>

<details id="yes-i-have-standard-edition-installed">

<summary>Yes, the Standard Edition</summary>

Skip ① and go straight to [② Install v1.51 patch](/getting-started/download-and-install-v1_51-patch/).

</details>

<details id="yes-i-have-deluxe-edition-installed">

<summary>Yes, the Deluxe Edition, or via EA App / Origin</summary>

You're already on the latest version, so you can skip both ① and ②.

</details>

## 2. Vanilla or Remaster?

* Mostly playing public multiplayer on Reclamation servers? Stick with _Vanilla_.[^1]
* More into singleplayer or LAN parties with friends? Go for _Remaster_.[^2]
* Can't decide? _Remaster_ is a safe bet, and you can still switch back to vanilla whenever you like.[^3]

<details id="i-prefer-vanilla">

<summary>I'll play Vanilla</summary>

[③ Install BF2142 Hub](/getting-started/download-and-install-bf2142-hub/) → [④ Apply OpenSpy patches](/getting-started/apply-openspy-patches/) → [⑤ Install the map pack](/getting-started/install-map-pack/) → [⑥ Create an account](/getting-started/create-account/)

</details>

<details id="i-prefer-remaster">

<summary>I'll play Remaster</summary>

[③ Install BF2142 Hub](/getting-started/download-and-install-bf2142-hub/) → [④ Apply OpenSpy patches](/getting-started/apply-openspy-patches/) → [⑥ Create an account](/getting-started/create-account/) → [Install Project Remaster](/advanced/project-remaster/install-project-remaster/) → [Launch Project Remaster](/advanced/project-remaster/configure-remaster-launcher/)

You only need [⑤ Install the map pack](/getting-started/install-map-pack/) if you also want to play on Reclamation servers.

</details>

<details id="im-using-windows-xp-32-bit">

<summary>I'm on Windows XP (32-bit)</summary>

BF2142 Hub is a 64-bit app and won't run on 32-bit systems, so stick with Vanilla and skip ③ and ④.

Instead: [install the OpenSpy patches for XP](https://www.moddb.com/mods/bf2142-reclamation-xp-install-package/downloads/bf2142-reclamation-xp-install-package) ([why?](https://battlefield2142.co/faq#notwin32)) → [⑤ Install the map pack](/getting-started/install-map-pack/) → [⑥ Create an account](/getting-started/create-account/)

</details>

## Good to know

<details id="why-are-there-so-many-steps">

<summary>Why are there so many steps?</summary>

Getting a 20-year-old game running on a modern PC has a few spots where things can go sideways. We walk you through each one and explain why it matters, so you get it working first time.

</details>

<details id="why-didnt-our-guides-cover-bf2142unlocker">

<summary>Why don't the guides use BF2142Unlocker?</summary>

We love the classic way: it keeps the original interface and lets you create and join games just like back in the day. It takes a few more steps, but it's the authentic BF2142 experience.

Still keen on the Unlocker? Here's the [BF2142Unlocker guide](/advanced/addons-tweaks/bf2142unlocker/).

</details>

[^1]: Most players are on the Reclamation servers, and they're unmodded. You'll need to launch the game without any mods to join them.

[^2]: The Remaster mod adds high-resolution textures, new animations, new weapons and smarter bots.

[^3]: The Remaster Launcher lets you switch between modded and vanilla BF2142 whenever you like.
