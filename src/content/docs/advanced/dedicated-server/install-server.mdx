Want a proper, always-on server that doesn't need you to play on it? A dedicated server is the way to go. First, let's install it.

<GuideSummary step={1} total={3} time="5 minutes">

Download the server setup (140 MB), run it and follow the wizard. Then patch it in the next guide, or it can't go online.

</GuideSummary>

## Steps

<Steps>

1. Download the server setup from [Downloads](#downloads).

1. Double-click the `.exe` to start the installer. If <mark class="ui">User Account Control</mark> asks, click <mark class="ui">Yes</mark>.

1. Follow the wizard to finish the installation.

1. Next up: <GuideLink href="/advanced/dedicated-server/install-server-patch/" label="Install the server patch" />

   _Don't skip this_, or your server can't go online.

</Steps>
