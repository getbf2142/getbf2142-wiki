The in-game menus only offer a few settings: singleplayer lets you change rounds per map and bot skill, and LAN adds tickets, friendly fire and team ratio. But you can change far more, like respawn time, man-down time or the number of players needed to start, in singleplayer and LAN alike.

There are two ways to do it. Pick the one that suits you.

| | Option 1: `ServerSettings.con` | Option 2: `GameLogicInit.con` |
| --- | --- | --- |
| Applies to | Every mod | One mod |
| In-game menu settings | Always overridden by the file | Still work, unless you override them |
| Best for | Set-and-forget changes | Most people, **recommended** |

## Option 1: Edit ServerSettings.con

Everything in this file overrides the in-game menu. For example, if the file says tickets 100 but you set 300 in the menu, the game uses 100.

<Steps>

1. Open `Documents\Battlefield 2142\Profiles\Default\ServerSettings.con` with a text editor.

1. Change the values you want. Only edit existing lines and don't add new ones. Note that `GameServerSettings...` lines aren't the same as `sv...` settings.

1. Save the file.

1. Right-click the file → <mark class="ui">Properties</mark>, tick <mark class="ui">Read-only</mark> and click <mark class="ui">OK</mark>.

   This step matters: otherwise BF2142 often overwrites your changes when it starts. ([More background](https://classic-battlefield-modding.fandom.com/wiki/Changing_Ticket_Counts).)

</Steps>

## Option 2: Edit GameLogicInit.con

Add only the settings you want to override, usually the ones the menu doesn't offer, and leave everything else to the menu.

<Steps>

1. Open `mods\<MOD>\GameLogicInit.con` in your game folder with a text editor.[^1]

1. Add the settings you want at the end of the file, one per line. See the [list below](#list-of-server-settings).

1. Save the file.

   Can't save? Copy the file to your desktop, edit it there, then copy it back.

</Steps>

<Aside type="tip">

It's easy to forget what you've added. To switch a setting off, put `rem` at the start of its line. To switch off a whole block, wrap it in `beginrem` and `endrem`.

</Aside>

## List of server settings

<details id="commonly-used-settings">

<summary>Commonly used settings</summary>

A handy starting point:

```batch
rem ↓ show your server in the online server browser
sv.internet 1
rem ↓ welcome message on the loading screen
sv.welcomeMessage "Welcome!"
rem ↓ remove "The game will start when 1 more player join" in LAN games
sv.numPlayersNeededToStart 1
rem ↓ seconds to wait before respawning
sv.spawnTime 10
rem ↓ seconds you can be revived by a medic
sv.manDownTime 10
rem ↓ 100% tickets (overrides singleplayer's 200%)
sv.ticketRatio 100
sv.teamRatioPercent 100
sv.autoBalanceTeam 0
sv.roundsPerMap 1
sv.useGlobalRank 1
sv.useGlobalUnlocks 1
sv.minUnlockLevel 5
sv.botSkill 0.2
rem ↓ no friendly fire from mines
sv.friendlyFireWithMines 0
```

</details>
