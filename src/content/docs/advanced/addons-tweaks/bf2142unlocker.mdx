BF2142Unlocker runs a master server right on your PC, so you get all unlocks and stats even offline, without any manual patching. It also lists servers from several master servers and lets you join or host games from one simple window.

<div class="figure-row"><figure><img src="/assets/unlocker_2.webp" alt="Hosting a master server in BF2142Unlocker" loading="lazy" /><figcaption><p>Host a master server</p></figcaption></figure> <figure><img src="/assets/unlocker_1.webp" alt="Joining a multiplayer game in BF2142Unlocker" loading="lazy" /><figcaption><p>Play multiplayer</p></figcaption></figure></div>

<details id="special-remarks">

<summary>Good to know</summary>

* <mark class="ui">Host</mark> only starts the _master server_ (logins and unlocks). You still start the actual game server from inside the game.
* You can host both even with no network connection at all.
* <mark class="ui">Host</mark> listens on all networks (`0.0.0.0`), while <mark class="ui">Singleplayer</mark> only listens on this PC (`127.0.0.1`).
* The Unlocker modifies the OpenSpy patches. To play on OpenSpy again, run BF2142 Hub as administrator and [reinstall the OpenSpy patches](/getting-started/apply-openspy-patches/).

</details>

## Setting up

<Aside type="caution">

Some antivirus tools (like Norton) wrongly flag Unlocker files and quarantine them. The files are safe, so restore them and add the Unlocker folder to your antivirus exceptions.

</Aside>

<Steps>

1. Extract the download and launch `BF2142Unlocker.exe`.

1. Set the game path to your `Battlefield 2142` folder, usually `C:\Program Files (x86)\Electronic Arts\Battlefield 2142`.

1. Enable <mark class="ui">LAA-Patch</mark>. It lets the game use up to 4 GB of RAM and prevents crashes.

1. Tick <mark class="ui">Window Mode</mark> and set your resolution. Switch to fullscreen once everything works, since windowed mode makes troubleshooting easier.

1. Choose your <mark class="ui">Mod</mark>, set your <mark class="ui">Player name</mark>, and check the <mark class="ui">Video</mark>, <mark class="ui">Audio</mark> and <mark class="ui">HUD</mark> settings.

1. Click <mark class="ui">Host</mark> to start your master server, then start a game from inside BF2142.

</Steps>

<details id="windowed-mode-distortion">

<summary>The game looks distorted in windowed mode?</summary>

Enable High DPI Aware for both game executables:

1. In your `Battlefield 2142` folder, right-click `BF2142.exe` → <mark class="ui">Properties</mark> → <mark class="ui">Compatibility</mark> → <mark class="ui">Change high DPI settings</mark>.
2. Tick <mark class="ui">Override high DPI scaling behavior</mark>, set it to <mark class="ui">Application</mark> and click <mark class="ui">OK</mark>.
3. Repeat for `BF2142Patched.exe`.

</details>

## Hosting a game for friends

<Aside type="caution">

Allow `BF2142.exe` and `BF2142Patched.exe` (in the game folder) and `BF2142Unlocker.exe` (in the Unlocker folder) through Windows Firewall on both private and public networks: <mark class="ui">Control Panel</mark> → <mark class="ui">Windows Defender Firewall</mark> → <mark class="ui">Allow an app or feature through Windows Defender Firewall</mark>.

</Aside>

<Steps>

1. Click <mark class="ui">Host</mark>, then start your game server as described in [Host a server](/getting-started/host-server/), including the notes under _Before you start_. For internet play, forward the two extra Unlocker ports too.

1. Share your IPv4 address with your friends: local for LAN, public for the internet.

1. Your friends enter that address in the Unlocker's <mark class="ui">IP-Address</mark> box, tick <mark class="ui">Auto join server</mark> and click <mark class="ui">Connect</mark>. That connects them to your master server and game server in one go.

</Steps>
