BF2142 was built for 4:3 screens. The v1.51 patch added widescreen support, but it mostly stretches the picture, so the HUD still looks off at 16:9. The Project Remaster team's HUD fix resizes it properly.

## Before you start

* Your game folder is where `BF2142.exe` lives, usually `C:\Program Files (x86)\Electronic Arts\Battlefield 2142`.
* In the steps, `<MOD>` means `mods\bf2142` for vanilla, or your mod's folder.

## Steps

<Aside type="tip">

**Using Project Remaster?** It's built in: tick <mark class="ui">Widescreen Fix</mark> and <mark class="ui">HUD-fix</mark> in the Remaster Launcher's <mark class="ui">Settings</mark> tab.[^1] To turn it off, untick both and click <mark class="ui">Clear Cache</mark> on the <mark class="ui">Help</mark> tab.

</Aside>

<Steps>

1. Download the patch from [Downloads](#downloads) and extract it. You'll get two files: `Menu_server_hudfix.zip` and `Shaders_client_hudfix.zip`.

1. Copy both files into `<MOD>`.

1. Back up `ClientArchives.con` (copy it as `ClientArchives_o.con`), then open the original with a text editor and add this line at the very top:[^2]

   ```batch
   fileManager.mountArchive Shaders_client_hudfix.zip Shaders
   ```

1. Back up `ServerArchives.con` the same way, then add this line at the very top:

   ```batch
   fileManager.mountArchive Menu_server_hudfix.zip Menu
   ```

   Can't save your changes? Copy the file to your desktop, edit it there, then copy it back.

1. Turn on widescreen when you launch the game:

   * **BF2142 Hub:** tick <mark class="ui">TURN ON WIDESCREEN</mark>.
   * **Remaster Launcher:** enable <mark class="ui">Widescreen Fix</mark> in <mark class="ui">Settings</mark>.
   * **Desktop shortcut:** add `+widescreen 1` to the <mark class="ui">Target</mark> field ([how](/advanced/addons-tweaks/custom-shortcuts/)).

</Steps>

## Good to know

* Undo the changes before joining Reclamation or other online servers, unless the server uses this fix too.
* Hosting with this fix? Players who join need it too.
* To uninstall, restore your backups and [clear the cache](/help-centre/troubleshoot/#a03-delete-profile-and-cache).
