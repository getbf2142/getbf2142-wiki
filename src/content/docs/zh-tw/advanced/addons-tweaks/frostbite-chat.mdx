喜歡 BF3、BF4 那種聊天介面？這個擴充能讓 BF2142 也換上類似的樣式，士兵和指揮官視角都有。

## 開始之前

* 要先裝好[寬螢幕 HUD 修正](/zh-tw/advanced/addons-tweaks/hudfix/)。有裝 Project Remaster 的話，在 Remaster Launcher 開啟 <mark class="ui">HUD-fix</mark> 就好。
* 遊戲資料夾就是 `BF2142.exe` 所在的地方，通常在 `C:\Program Files (x86)\Electronic Arts\Battlefield 2142`。
* 擴充要放進 `mods\bf2142`（原版），或你的模組資料夾。

## 步驟

<Steps>

1. 從[下載](#下載)抓擴充，聊天有背景和沒背景的版本都有，挑你喜歡的。

1. 照著裡面的 `README.txt` 做就好。

</Steps>

## 你可能想知道

* 要進 Reclamation 或其他線上伺服器前，記得先改回來，除非伺服器也有用這個擴充。
* 用這個擴充開伺服器？加入的玩家也要裝。
* 想移除的話，照 README 把安裝時改的地方改回來就好。
