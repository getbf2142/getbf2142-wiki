<details id="can-my-pc-handle-this-game">

<summary>我的電腦跑得動嗎？</summary>

幾乎都可以。只要你的電腦跑 Windows 7 以上、平常用起來不卡，大概就沒問題。

最低需求：

* 作業系統：Windows XP，需要管理員權限
* 處理器：1.7 GHz Intel Pentium 4 / AMD Athlon XP
* 記憶體：512 MB
* 磁碟空間：2.2 GB
* 顯示卡：NVIDIA GeForce FX 5700 / ATI Radeon 9500[^1]
* 解析度：800 × 600，16 位元色彩

</details>

<details id="can-i-play-this-game-on-mac">

<summary>可以在 Mac 玩嗎？</summary>

舊款 Intel Mac 可以。EA 在 2007 年推出的 Mac 版其實不是原生程式，而是透過 _Cider_ 相容層跑 Windows 版。它是 32 位元程式，所以 macOS 10.15 Catalina 以後的版本和 Apple Silicon Mac 都跑不了。

<Embed url="https://www.myabandonware.com/game/battlefield-2142-vdw#Mac" title="Battlefield 2142 for Mac v1.25 (1.9 GB)">

來源：[My Abandonware](https://www.myabandonware.com/)

</Embed>

用新款 Mac 的話，可以試試這些方法：

* 在虛擬機器執行 Windows（例如 [VirtualBox](https://www.virtualbox.org/) 或 [VMware](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)）
* 用 [Boot Camp](https://support.apple.com/en-au/guide/bootcamp-assistant/welcome/mac) 安裝 Windows（只限 Intel Mac）
* 試試 [Wine](https://www.winehq.org/) 或 [PlayOnMac](https://www.playonmac.com/en/)

## 步驟

<Steps>

1. 從[下載](#下載) → [標準版](#標準版)下載遊戲。

1. 把 `.rar` 或 `.zip` 裡的東西全部解壓縮到一個新資料夾，放桌面就可以。[^2]

1. 打開那個資料夾，點兩下 `setup.exe` 開始安裝。[^3]如果跳出 <mark class="ui">User Account Control</mark>，按 <mark class="ui">Yes</mark>。

1. 跟著安裝精靈走，有幾個地方要留意：

   * 看到 <mark class="ui">This game has only been tested on WinXP(32bit)</mark> 時，按 <mark class="ui">Confirm</mark> 就好，不用理它。
   * 要輸入序號時，記得選跟你版本對應的那組：[^4]

     <Tabs syncKey="edition">
     <TabItem label="標準版序號">

     ```text
     SDV5-JZDE-L6B8-P2Q4-1911
     SVMV-LBNV-W7W5-J3X4-1911
     E6HH-DWUG-U8X1-R8F0-1911
     UTFP-4DMN-D2U0-X3T3-1911
     TRCL-YBIJ-D4H4-Y3O5-1911
     ```

     </TabItem>
     <TabItem label="豪華版序號">

     ```text
     7GT3-VNQL-GRXP-NUE4-FR74
     ```

     </TabItem>
     </Tabs>

   * 安裝路徑最好用預設的（`C:\Program Files (x86)\Electronic Arts\Battlefield 2142`），我們的指南都是照這個路徑寫的。
   * 選 <mark class="ui">English version</mark>，之後 [Project Remaster](/zh-tw/advanced/project-remaster/) 才能用高解析度的英文字型。
   * BattleCammo（遊戲內語音）按 <mark class="ui">Cancel</mark> 跳過。
   * 選 <mark class="ui">No, install GameSpy Comrade later</mark>。GameSpy 在 2014 年就[關站](https://en.wikipedia.org/wiki/GameSpy#Shutdown)了，Comrade 早就不能用。
   * 問你要不要註冊 EA 帳號時，按 <mark class="ui">REGISTER LATER</mark>，這款遊戲的 EA 伺服器已經關了。
   * PunkBuster 也跳過，現在已經沒有伺服器在用了。

1. 裝好後關掉精靈，但<em>先別開遊戲</em>，不然它只會一直叫你放光碟。

1. 下一步：<GuideLink href="/getting-started/download-and-install-v1_51-patch/" label="安裝 v1.51 更新檔" />

   _千萬別跳過_。這個更新檔會拿掉光碟檢查，沒裝的話遊戲根本開不起來。裝的是豪華版？那已經是 v1.51 了，直接看 <GuideLink href="/getting-started/download-and-install-bf2142-hub/" label="安裝 BF2142 Hub" />

</Steps>

<details id="important-notes">

<summary>該選哪個版本？</summary>

* 新手就選<em>標準版</em>，我們的指南都是用它寫的。
* 反正更新到 v1.51 之後，每個版本都一樣，不用想太多。
* 這些不是官方管道。但除了買二手 DVD（而且光碟版本身也連不上線），能選的也不多了。不放心的話，可以先用防毒軟體掃一下，或改用你信得過的來源。

* 一定要有說明書，序號就印在說明書背面。
* 光碟和說明書要是同一個版本，不然序號不能用。
* 你的電腦要有 DVD 光碟機。
